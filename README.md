TeleFolders — это менеджер папок для управления чатами и каналами в Telegram. Мы обновляем приложение, чтобы сделать его быстрее, удобнее и функциональнее!  

---

## 📋 Описание новой версии

В версии **v1.0** мы внедряем:  

- **React и Electron** для создания нативного и кроссплатформенного интерфейса.  
- **UI Kit Gravity-UI** для улучшения внешнего вида.  
- **Новые функции**:  
  - Пагинация для больших списков чатов.  
  - Возможность выхода из групп и каналов.  
  - Просмотр чатов и каналов в Telegram.  
  - Отображение фотографий каналов и чатов.  
  - Оптимизация производительности и исправление багов.
