## Definition of Done для любой задачи

1. `tsc --noEmit` и `pnpm lint` зелёные, типы строгие.
2. Компонент имеет стори, логика — тест.
3. Все строки через Paraglide.
4. Ни одного импорта `@mtcute/*` вне `src/telegram/`.
5. Ошибки обработаны и показаны пользователю осмысленно.
6. Отклонение от ТЗ — правка `ТЗ.md` в том же PR.
